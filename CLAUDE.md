# Docs

`docs/` records the current state of planning (use cases, product, architecture).

- Only record what the user has confirmed. No proposals, rationale or added detail.
- Keep it very brief and readable. Match the user's level of certainty: a "maybe" stays a "maybe".

# Tooling

The project uses Vite+ (`vp`): @AGENTS.md

# Context

[Issue 1](https://github.com/bcye/excalidraw-map/issues/1) records the initial planning session: why things were chosen, options evaluated, and working assumptions for the prototype. Its comments hold the full conversation. Read it when a design decision needs context.
